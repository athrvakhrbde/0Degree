# 0Degree - Don't Dropout

A modern, responsive website with smooth snap scrolling.

## Features

- ✅ Fully responsive design
- ✅ Dark mode (#262626 background)
- ✅ Optimized performance
- ✅ SEO optimized
- ✅ Accessibility compliant (ARIA labels, semantic HTML)
- ✅ Cross-browser compatible
- ✅ Smooth snap scroll animations (PowerPoint-style)
- ✅ Touch and trackpad support

## File Structure

```
/
├── index.html      # Main HTML file
├── styles.css      # All styles
├── script.js       # JavaScript functionality
├── india-map.svg   # Hero background image
└── README.md       # This file
```

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

## Performance

- Optimized font loading with `display=swap`
- Preconnect to Google Fonts
- Efficient CSS with variables
- Optimized JavaScript with requestAnimationFrame
- Smooth scroll snap functionality

## Accessibility

- Semantic HTML5 elements
- ARIA labels and roles
- Proper heading hierarchy
- Keyboard navigation support
- Screen reader friendly

## Deployment

Simply upload all files to your web server. No build process required.
